# BRIDGE-D 第一篇 BRM 论文范围

本文保持软件论文的有限范围，不把 BRIDGE-D 写成一种新的抑郁理论，也不把
Construct Map 写成自动发现心理构念的工具。

## 文章结构

1. Introduction：现有量表分析工作流的问题。
2. Software design：BRIDGE-D 的设计与实现。
3. Statistical validation：与参考实现的比较。
4. Simulation study：统计性能验证。
5. Empirical application：真实数据案例。
6. Discussion：贡献、局限与未来发展。

## Construct Map 在本文中的作用

Construct Map 是 BRIDGE-D 的一项可复用功能，也是经验应用的一部分。它回答的
问题是：在不把内容标签交给 PCA 或聚类算法的情况下，真实作答数据中的连续坐标
和邻近关系是否与研究者预先定义的内容分组相符。

这不是“算法自动命名构念”。分析顺序必须保持为：

1. 在查看坐标结果前定义内容分组和比较假设；
2. 只用作答数据拟合 Spearman 相关、PCA 坐标和层次聚类；
3. 拟合后才用预设标签检验组间距离、置换概率和重抽样稳定性；
4. 同时报告不一致结果，不把连续分离改写成离散分类成功。

## 三类数据在论文中的分工

### Granwald 公开数据

用于展示多个共同施测量表如何进入同一套可复现工作流，并检查样本拆分后的坐标
稳定性。它主要支持软件可运行性和分析可复现性。

### NSDUH 2021–2024

作为第一篇论文的验证性案例。它展示 BRIDGE-D 如何把预先定义的内容分组与真实
人群数据中的经验结构联系起来。现有结果支持 PCA 连续坐标上的部分分离，其中包括
生理与认知／情感症状的对比，以及 SDS 局部图中的独处／角色活动与人际／社交功能
对比。该案例不使用复杂抽样权重，因此只解释为当前成人抑郁发作完整案例样本中的
结构验证，不作美国人口参数估计。

### 尚未取得的临床数据

如果数据包含可对应的条目、多个共同施测量表和足够样本，可按同一流程做临床样本
中的外部复现或扩展。这会提供原创性更强的经验材料，但它不是 v0.3.1 发布或第一篇
软件论文成立的前提。在取得变量表、计分规则和数据质量信息前，不预设它一定能用于
Construct Map，也不把它写成已经完成的结果。

## 经验应用的最低报告内容

- 内容分组及其定义时间；
- 纳入排除、完整案例数量和缺失情况；
- 条目相关、PCA 方差解释率、坐标与层次聚类结果；
- 预设分组的距离或置换检验；
- Bootstrap 或拆分样本稳定性；
- 连续坐标、聚类和临床亚型之间的解释边界；
- 若为调查数据，是否使用权重、分层和整群设计。

## 当前边界

第一篇论文不要求新增 CFA、IRT、监督分类器或自动构念命名。临床数据若可用，可以
加强经验应用；若不可用，NSDUH 仍可承担“预设内容分组与经验结构联系”的验证案例。
