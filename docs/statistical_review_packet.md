## 1. 软件做什么

BRIDGE-D 把心理量表定义成机器可读的 TOML 文件：条目、反应选项、计分规则、缺失处理、切点。工具读取定义，完成计分，再把两个在同一批受试者身上施测的量表放在一起比较。

R 的统计包负责推断。BRIDGE-D 负责定义和流程的标准化：同一个量表在不同项目里应当有一致的计分规则、缺失规则和可核对的版本。

当前版本支持：

- 计分：求和、维度分、反向题、三种缺失策略；
- 比较：Cronbach's α、Pearson/Spearman、ICC(2,1)、Bland-Altman、Cohen's κ、等百分位链接；
- 模拟：已知真值的合成数据、恢复研究、样本量规划；
- Construct Map：Spearman条目相关、PCA或非度量MDS二维坐标、平均连接聚类和Bootstrap稳定性；
- 报告：Markdown 与中文 Word 三线表。

范围限制：两个量表必须共同施测；不处理复杂抽样权重；不做 CFA、IRT、测量不变性。

## 2. 数据结构

```toml
id = "phq9"
version = "1.0.0"
source = "Kroenke et al. 2001"
validation = "source-verified"

[[items]]
id = "phq1"
construct = "anhedonia"
response = "phq_0_3"

[scoring]
missing_min_answered = 7
missing_strategy = "prorate"

[scoring.total]
method = "sum"
items = "all"
```

每个定义有 `id@version` 和 SHA-256 哈希。哈希覆盖条目、反应选项、计分、切点、缺失规则，不覆盖注释、来源和验证状态。报告记录哈希前 12 位，用来判断两项研究是否用了同一份可执行定义。

## 3. 估计量与实现

| 统计量 | 定义 | 位置 |
|---|---|---|
| Cronbach's α | 完整作答条目；`k/(k-1) * (1 - Σ item var / total var)` | `compare.cronbach_alpha` |
| ICC(2,1) | 双向随机效应、绝对一致性、单次测量；Shrout & Fleiss (1979) | `compare.icc21` |
| Bland-Altman | 均差、差的标准差、LoA = 均差 ± 1.96 SD | `compare.bland_altman` |
| Cohen's κ | 不加权；观察一致率与期望一致率 | `compare.cohen_kappa` |
| 等百分位链接 | 每个 A 分数取中位百分位，再用 B 的分位数线性插值 | `compare.equipercentile` |
| Bootstrap | 按受试者重抽样；百分位区间；默认关闭，`--bootstrap N` 开启 | `compare.equipercentile` |
| Construct Map | 条目Spearman相关；PCA载荷或非度量MDS标定；完整相关距离上的平均连接聚类 | `construct_map.py` |
| 缺失处理 | prorate（`总分 × 条目数 / 已答数`）、zero、listwise；设有最少答题数 | `instrument._aggregate` |
| 模拟 | 单因子模型；两个潜变量相关 `latent_r`；正态阈值生成有序反应；MCAR/MNAR | `simulate.py` |

对 ICC 的选择：两个量表是固定的工具，不是从总体抽取的评分者。严格说 ICC(3,1) 或 CCC 更贴合这个设计。当前实现用 ICC(2,1)，因为领域惯例如此。这一点请重点判断。

等百分位链接的实现与 R 的 `equate` 不同。`equate` 用半区间线性插值，BRIDGE-D 用中位百分位加 `numpy.quantile`。百分位秩完全一致，链接分数在固定数据上最大差 0.98 分，平均差 0.27 分。

## 4. 已做的验证

### Level 1：与 R 对照

固定数据 120 例，含反向计分题，无缺失。R 4.3.3，psych 2.6.9，irr 0.85，equate 2.0.9。

| 指标 | Python | R | 绝对差 |
|---|---|---|---|
| α（PHQ-9） | 0.84752790 | 0.84752790 | 4.3e-14 |
| α（示例量表） | 0.72502617 | 0.72502617 | 3.6e-14 |
| ICC(2,1) | 0.30195482 | 0.30195482 | 8.8e-15 |
| Cohen's κ | 0.00662252 | 0.00662252 | 3.9e-16 |

链接部分：百分位秩差为 0；链接分数最大差 0.983，平均差 0.270。κ 接近 0 是因为两个量表切点体系不同，这一项只验证数值一致性。

### Level 2：模拟恢复

条目阈值来自公开的 NHANES 2017-2018 PHQ-9 数据（5,533 人，9 个条目，任一题缺失 8.4%）。A 量表 9 题，B 量表 12 题，载荷固定 0.70。网格为 n 42/100/200 × `latent_r` 0.2/0.4/0.6 × 缺失（无、MCAR 20%、MNAR 20%），每个条件 200 次重复。真值在每个条件下用 10 万人样本单独生成，覆盖率对照同机制真值。

| n | latent_r | 缺失 | 估计 r | 同机制真值 | 偏差 | 覆盖率 | CI 宽度 | 链接 RMSE |
|---|---|---|---|---|---|---|---|---|
| 42 | 0.6 | 无 | 0.426 | 0.458 | -0.033 | 0.865 | 0.489 | 3.40 |
| 42 | 0.6 | MCAR | 0.382 | 0.450 | -0.068 | 0.870 | 0.797 | 4.32 |
| 200 | 0.6 | 无 | 0.448 | 0.458 | -0.010 | 0.855 | 0.221 | 2.17 |
| 200 | 0.4 | MNAR | 0.273 | 0.273 | +0.000 | 0.900 | 0.258 | 2.25 |

## 5. 已知问题

1. **覆盖率低于 0.95。** n=42、`latent_r`=0.6 时，Fisher 区间覆盖约 87%；n=200 时 85.5%。区间偏窄，读者会高估精度。
2. **链接插值约定不同。** 与 `equate` 的链接分数最大差 0.98 分。百分位定义一致，差别在插值。
3. **MCAR 20% 是压力测试。** 每个条目独立缺失 20%，加上最少答题数规则，最后只剩约 40% 的受试者。NHANES 任一题缺失率为 8.4%。
4. **没有 MAR 条件。** 当前只有 MCAR 和 MNAR。临床数据里缺失常与严重度相关，MAR 更现实。
5. **模拟模型是单因子。** 没有方法因子、天花板效应、条目数变化、反应等级变化。
6. **ICC(2,1) 的概念问题。** 两个量表是固定工具，把它当作随机评分者是否合适，需要你判断。
7. **Bland-Altman 只在原始分数上做。** 量程不同时没有重标度，只能作描述性参考。
8. **prorate 在 MNAR 下有偏。** 高条目分数更容易缺失时，总分被低估。没有做敏感性分析。
9. **链接尾部不稳。** 汇总只取 A 的 5% 到 95% 分位；尾部没有平滑，没有单独报告。
10. **没有 CFA 和测量不变性。** 这超出当前论文范围，但如果审稿人要求结构效度，会是缺口。

## 6. 具体问题

1. 两个固定量表之间，主指标用 ICC(2,1)、ICC(3,1) 还是 CCC？如果继续用 ICC(2,1)，论文里应如何说明？
2. 覆盖率不足时，应该换 BCa 或 bootstrap 区间，还是在论文里作为限制报告？如果换，n 小于多少时强制使用？
3. Fisher 区间用在有序总分上是否可接受？是否应该默认改用 bootstrap？
4. 等百分位链接应该实现 `equate` 的半区间插值，还是保留当前实现并在论文里说明差异？
5. 链接是否应该加平滑（log-linear 或 kernel）？在什么样本量下值得做？
6. 缺失处理的默认策略应该是 prorate 还是 listwise？最少答题数的阈值有没有更好的设定方式？
7. 模拟网格还缺哪些条件？我列了天花板效应、条目数、反应等级，是否还有更关键的？
8. 覆盖率的真值应该用同机制大样本真值，还是无缺失真值？我选了前者，请判断这个选择是否合理。
9. 是否应该同时报告原始分数和标准化分数的 ICC？
10. 真实数据案例至少需要多大的样本、什么样的设计，等百分位链接才值得写进论文？
