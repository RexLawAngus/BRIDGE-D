# 锚定条目应用示范

在 `Current Version` 根目录运行：

```powershell
python validation/anchor_use_case/run_suicide_demo.py
```

默认执行参与者 Bootstrap 1000 次、标签置换 9999 次，种子为 20261127。
可用 `--bootstrap`、`--permutations`、`--seed` 修改；数据路径与输出路径见 `--help`。
不执行原有验证脚本的主函数，不运行第 4 节模拟或 R 参考核对。

Granwald 使用实际原始列 `PHQ_9` 和 `SDS_19`，沿用已有 `AC_fails <= 2` 筛选和量表计分配置。
PHQ-9 阳性定义为大于 0，Zung SDS 阳性定义为大于 1。两者也各自导出非零作答数；SDS 非零率为 100% 不等于阳性率。
内容组来自已有 `semantic_tags.csv`，生理/非生理、人际/非人际分别作为独立标签体系。

NSDUH 用 `YEAR + QUESTID2` 在本数据集内一对一匹配原始 `SUICTHNK`。
按原始 1=是、2=否转为 1/0，94、97 等其余编码设为缺失；不将 `IRSUICTHNK` 插补版本作为第二锚点。
在原 12 指标完整的成人过去一年 MDE 样本中，进一步排除锚点缺失，另拟合 13 指标 PCA 应用地图。
四组标签沿用原有配置。NSDUH 只有一个独立意念锚点，不计算跨量表锚点收敛度。
该分析不使用调查权重或复杂抽样设计；比例和参与者 Bootstrap 仅描述选定样本。

两套数据独立加载、拟合、重抽样和导出。脚本只汇总两边的统计结果，不合并两套参与者数据。

## 结果文件

- `RESULTS_ANCHOR_DEMO.zh-CN.md`：论文 5.3 节所需数值、Top-5、内容组距离及 p 值。
- `outputs/Granwald/`、`outputs/NSDUH/`：各自的四张 `anchor_*.csv`、严格 JSON、300 dpi PNG 与矢量 SVG。
- 各输出目录包含拟合坐标、相关/距离矩阵、预设标签、分析参数与 `provenance.json`。
  后者记录原始列名、选样计数、计分配置哈希及输入文件 SHA-256；不导出参与者作答表。

完整距离为 `1 − Spearman r`；二维距离及质心距离是 PCA 投影距离。
Bootstrap 对每次抽中的参与者重新计算含并列秩的 Spearman 相关；CI 取有效条目对重抽样的 2.5%/97.5% 分位数。
Top-K 稳定性以锚点整行相关均有效的重抽样为分母，同时提供分母与入选次数。
邻近同分时按稳定条目 ID 排序。

内容组检验固定全部锚点的位置，并从内容组和置换池剔除全部锚点。
各标签体系内置换剩余标签，保持组大小，使用较小距离方向的 `(b+1)/(B+1)` Monte Carlo p 值，未校正多重比较。
跨量表距离百分位以全部跨量表条目对为参照，采用中秩百分位；它是描述性排名，不是 p 值。
